# DoughFlow

Dough production and inventory management PWA.

Supports English, Russian, and Kyrgyz.

## v1
- Admin, Hamurchi, Naan/Leposhka Maker, Salesman roles
- Sack-based dough production (1–9 full sacks + optional 0.5)
- Editable recipes and actual consumption
- Package-aware inventory
- Supabase/PostgreSQL backend
- PWA support
- English, Russian and Kyrgyz UI with live language switching
- Mobile-first iOS-style dashboard

See `docs/DEPLOY.md` for deployment instructions.
